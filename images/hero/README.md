# ヒーロー用ブロブ素材

XD から **ブロブごとに個別** で書き出し、このフォルダに配置してください。

差し替え手順はリポジトリ直下の **[PENDING.md](../../PENDING.md)**（PND-001, PND-002）を参照。

## 想定ファイル名（例）

| ファイル | 用途 |
|----------|------|
| `blob-red-left.svg` | 左側の赤ブロブ |
| `blob-red-right.svg` | 右側の赤ブロブ |
| `blob-yellow-top.svg` | 上部の黄ブロブ |
| `blob-blue-bottom.svg` | 下部の青ブロブ |
| `logo.svg` または `logo.png` | 中央ロゴ（2×2 カラフル四角） |

※ 枚数・命名は XD のレイヤー構成に合わせて調整可。1 枚にまとめた合成 PNG はアニメ用に使わないこと。
